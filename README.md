# 🛒 Lojinha da Unidade

Loja virtual simples desenvolvida como projeto de estudo de **Bootstrap 5**, **HTML**, **CSS** e **JavaScript** para a matéria de Práticas de 
Programção na Gran Faculdade

## 📸 Preview

![Preview da loja](img/produto_1.webp)

## ✨ Funcionalidades

- Listagem de produtos com imagem, código, cor e preço
- Controle de quantidade com botões + e -
- Cálculo automático do total por produto
- Soma automática do subtotal
- Layout responsivo com Bootstrap 5

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
- [Bootstrap 5.3.8](https://getbootstrap.com/)
- [Bootstrap Icons](https://icons.getbootstrap.com/)
